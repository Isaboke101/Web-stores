# Web Pages Repository

This repository serves as a centralised storage space for completed client website projects. Each client’s website is organised into its own folder, which contains all necessary files for deployment and maintenance.

---

## 📂 Repository Structure

- **/ClientName/**  
  Each folder is named after the client (or project identifier).  
  Inside, you’ll find:
  - `index.html` (main entry point)
  - `/assets/` (images, fonts, icons, etc.)
  - `/css/` (stylesheets)
  - `/js/` (scripts)
  - Any additional files specific to the client’s site

---

## 🚀 Purpose

- Maintain a clean archive of completed client websites.
- Provide easy access for updates, backups, or redeployment.
- Ensure consistency in folder organisation across projects.
